SWEET BIRTHDAY WEBSITE — DARK + MUSIC + SRC MEDIA

CARA MENJALANKAN
1. Extract ZIP.
2. Masukkan file musik bernama music.mp3 ke folder utama (sejajar dengan index.html).
3. Masukkan foto dan video ke folder assets sesuai nama di bawah.
4. Buka index.html atau jalankan dengan Live Server.

MEDIA SRC
- assets/flowers.mp4 : video halaman Beautiful Flowers
- assets/love.jpg : foto halaman I Love You
- assets/memory-1.jpg : foto galeri Our Memories
- assets/memory-2.jpg : foto galeri Our Memories
- assets/memory-3.jpg : foto galeri Our Memories

Semua media dipanggil langsung dari atribut src di index.html, sama seperti
music.mp3 pada elemen audio. Tidak ada tombol upload di halaman.

MUSIK
File music.mp3 diletakkan di folder utama. Website mencoba autoplay, tetapi
browser bisa memblokir autoplay bersuara sampai pengunjung berinteraksi.

Jika ingin lebih dari 3 foto Memories, duplikasi elemen memory-tile di index.html
dan sesuaikan nama file src-nya.
